Programming Projects

Airport Explorer - C++

Description: Airport Explorer is a C++ application developed to manage, search and analyse airport data. The application allows users to search for airports by country, name and IATA code, count airports by type, add airport records and save data.

The application also provides sorting functionality using different criteria, including airport name, country, type and elevation. Geographical functionality allows users to search for airports within a specified radius and identify the nearest airport using airport coordinate data. Airports can also be grouped by municipality.

Technologies Used: C++ | Object-Oriented Programming | STL | Data Structures | Algorithms | File Handling | String Manipulation | Geographical Calculations

Skills Demonstrated: Object-oriented programming, data structures, searching, sorting, file handling, problem solving and working with geographical data.

What I Learned: This project helped me develop my ability to structure a larger C++ application and apply programming concepts to a real dataset. I also developed my understanding of searching, sorting, data organisation and geographical distance calculations.

Evidence: View Airport Explorer on GitHub

BUSPROJECT - Python Ticket System

Description: I developed a working ticket system for the NCTX bus application. The system allows users to select and purchase tickets, while an administrative interface allows administrators to view purchased tickets and manage ticket information.

Technologies Used: Python | Visual Studio Code | CSV | Time Module

Skills Demonstrated: Python programming, conditional logic, data management, file handling, problem solving and user-focused software development.

What I Learned: I was given a starting point that involved reading a CSV file, but developed the system further through independent research and experimentation. I learned how to modify files, work with stored information and use nested conditional statements to control different parts of the program.

Evidence: The original project was developed using the NTU Git repository. A public GitHub repository can be added here when available.

Testing & Development

BUSPROJECT - Testing

Description: During the development of the BUSPROJECT, I regularly tested the program after making changes to identify errors and check whether the required functionality was working correctly.

Testing Approach: I tested different inputs, including words and abnormal numbers, to identify how the program responded to unexpected or incorrect information.

Context: One area I tested was the ticket billing process. When the program did not initially work as expected, I repeatedly modified and tested the code until the required functionality worked correctly.

What I Learned: Testing helped me understand the importance of identifying errors early, checking different possible inputs and using repeated testing to improve the reliability of a program.

Design & Problem Solving

Design and Technology Project

Description: This project involved identifying a problem in my everyday life and designing a potential solution. I identified that drinks such as coffee and tea could become cold after being left for an extended period of time.

Solution: I explored several possible solutions, including designing a cup that could retain heat. I ultimately developed the concept of a small heating device that could heat a cup when it was placed on the device.

Context: I used my own experience as the client because I regularly experienced the problem of drinks becoming cold before I had finished them.

Skills Demonstrated: Problem identification, design thinking, research, creativity, solution development and practical problem solving.
